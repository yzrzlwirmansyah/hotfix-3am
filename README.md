# 3 AM Hotfix: The Funniest Commit Message

[![make.fun](https://make.fun/badge/u-yuki-kato-3-am-hotfix-the-funniest-commit-message-e9f60106.svg)](https://make.fun/bounty/u-yuki-kato-3-am-hotfix-the-funniest-commit-message-e9f60106)

## The entry

> Revert the deploy that paged me at 3 AM; prod is back, my sleep schedule isn't

## Why it works

It is a real hotfix commit message first and a joke second: a terse imperative
revert, a pager, 3 AM, a deploy that should never have shipped. The laugh comes
from the second beat — prod is back, but the engineer who fixed it is not, and
no tired on-call dev needs that explained to them. Seventy-eight characters,
one sentence, no clichés, no setup left over.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

This writes the entry line to `./out/entry.txt`.
